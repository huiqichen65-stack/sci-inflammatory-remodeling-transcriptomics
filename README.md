# Injury-associated inflammatory-remodeling program after spinal cord injury

This repository contains the analysis code and cell-level annotations used in the revised manuscript **“Integrated single-cell and spatial transcriptomics identify an injury-associated inflammatory-remodeling program detectable near spinal cord lesions at chronic stages.”**

The study reanalyzes public mouse spinal cord injury transcriptomic datasets. GSE162610 is used for discovery, including atlas construction, myeloid refinement, resident-state analysis, trajectory and branch analyses, SCENIC, and CellChat. GSE234774 is used for independent single-nucleus and spatial validation.

## Cell-level annotations

Cell-level annotations are provided in `metadata/GSE162610_cell_annotations.csv.gz`.

The table contains 62,842 atlas cells. Key fields include:

- `cell_id` — cell barcode/identifier
- `myeloid_lineage` — final myeloid lineage assignment
- `resident_state` — resident-microglial state
- `branch_label` — formal trajectory branch label (`Shared_prebranch`, `Alternative`, or `Target`)

Fields that apply only to analytical subsets are left blank for cells outside those subsets.

## Analysis code

The scripts are organized into eight modules:

- `scripts/01_atlas` — metadata processing, QC, doublet detection, normalization, Harmony integration, clustering, and broad cell-type annotation
- `scripts/02_myeloid` — myeloid refinement, lineage assignment, resident-microglial states, transition analysis, temporal differential expression, and target-program definition
- `scripts/03_trajectory` — Monocle 3 trajectory reconstruction, root definition, branch topology, branch-dependent genes, dynamic modules, enrichment, and pseudobulk ssGSEA
- `scripts/04_regulatory` — SCENIC/GRNBoost2, cisTarget, AUCell, RSS/CSI, regulon timing, and target-program regulatory analysis
- `scripts/05_cellchat` — CellChat time-course and 7-dpi analyses, recipient-program integration, and signaling analysis
- `scripts/06_validation` — GSE234774 single-nucleus QC, clustering, myeloid annotation, AUCell/ssGSEA validation, and comparison with published annotations
- `scripts/07_spatial` — spatial QC, asset linkage, RCTD mapping, target-program scoring, lesion-zone analyses, spatial signaling, and anatomical anchoring
- `scripts/08_sensitivity` — lineage, dissociation, trajectory, CellChat, spatial cell-source, Tnf-source, and matched-null sensitivity analyses

## Data

Raw sequencing and spatial data are not duplicated in this repository. The source datasets are publicly available from NCBI GEO under accession numbers **GSE162610** and **GSE234774**.

The scripts expect raw data under:

```text
01_raw_data/GSE162610/
01_raw_data/GSE234774/
```

Generated intermediate objects and analysis outputs are written under `04_results/` and are not tracked by Git.

## Running the workflow

Run scripts from the repository root. The project root is resolved from `GLIA_PROJECT_ROOT`; if it is not set, the current working directory is used.

```r
Sys.setenv(GLIA_PROJECT_ROOT = normalizePath(".", winslash = "/"))
```

The workflow proceeds approximately in module order:

```text
01_atlas
  -> 02_myeloid
  -> 03_trajectory
  -> 04_regulatory / 05_cellchat
  -> 06_validation
  -> 07_spatial
  -> 08_sensitivity
```

Some downstream modules are complementary rather than strictly serial and use outputs generated by earlier scripts.

## Scope

The repository contains the analysis code supporting the revised manuscript and the requested cell-level annotations. Raw matrices, large intermediate R objects, and rendered figures are not redistributed.
